# 腾讯会议线上面试助手 0.3.4

本版本新增可切换的回答后端。默认行为保持不变：仍使用本地 Ollama/Qwen；用户也可以改用自己的 OpenAI 或 OpenAI-compatible API。

## 新增

- 设置面板新增“识别 / 回答”两个页签；
- 回答后端可选“本地模型”或“自己的 API”；
- API 模式支持填写 Base URL、模型名和 API Key；
- 支持标准 Chat Completions 响应，以及常见的分段文本响应；
- 远程 API 强制使用 HTTPS，本机 localhost 兼容接口可使用 HTTP；
- 可清除已保存 Key，并自动切回本地回答。

## Key 与隐私

- API Key 由 Electron `safeStorage` 调用 Windows 系统加密能力保存；
- 渲染界面只读取“是否已保存”，不会得到或回填 Key 明文；
- Key 不会写入仓库、网页存储或面试准备信息文件；
- 原始音频和语音识别仍完全在本机完成；
- API 模式会将识别题目、召回知识、最近对话和面试准备信息发送给用户指定的服务商，界面中已明确提示。

本版本没有内置或共享开发者 API Key，API 费用、额度、可用模型与数据政策均由用户选择的服务商决定。
