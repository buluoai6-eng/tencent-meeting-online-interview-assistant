# 线上会议面试助手 1.0.0（Windows）

1.0.0 将项目正式更名为“线上会议面试助手”，并从单一会议软件扩展为 Windows 多会议平台版本。GitHub 仓库同步更名为 `online-meeting-interview-assistant`。

## 新增

- 顶部“当前平台”入口，可在监听前确认音频目标；
- 自动识别腾讯会议、Zoom、Microsoft Teams、飞书/Lark、钉钉、Webex 和 Google Meet 窗口；
- 自定义窗口/屏幕选择，未列出的会议软件也可以使用；
- 指定平台未运行、自定义窗口关闭等情况下的明确错误提示；
- 平台路由状态与系统音频/麦克风双通道状态合并显示；
- 升级时自动迁移旧版本的面试准备信息、加密 API 设置和用户领域模块；
- 新增可切换的领域模块，术语纠错、领域知识和回答约束不再写死在主程序中；
- 内置“金融与会计”和“通用”模块，用户可以在应用“领域”页选择；
- 应用内可打开用户模块目录、编写说明和模板，并支持修改后重新扫描；
- 用户模块采用本地 JSON，加入文件大小、字段数量、重复 ID 和目录越界校验。

## 延续能力

- Windows 系统音频与麦克风分离，只有“对方”通道可以触发回答；
- FunASR 灰色流式临时字幕与 SenseVoice 最终转写；
- 本地 Qwen 或用户自己的 Chat Completions 兼容 API；
- 金融、会计、审计、估值和银行风险面试专项优化；
- 历史问答翻页和长回答滚轮查看。

## 当前范围

- 本版本仅支持 Windows 10/11；
- 当前的“多平台”能力指 Windows 上的多种会议软件和浏览器会议窗口，并非已经支持所有操作系统；
- Windows 回环音频仍是系统级音频，选择会议窗口不会自动隔离其他应用发出的声音。面试时建议关闭其他音频应用并佩戴耳机。

## 下载与升级

- `OnlineMeetingInterviewAssistant-Windows-1.0.0-portable.exe`：Windows 便携版主程序；
- `setup-local-models.ps1`：在 E 盘部署或复用本地语音识别与回答模型；
- `download-funasr-model.py`：FunASR 流式模型下载辅助脚本；
- `SHA256SUMS.txt`：上述发布文件的完整性校验值。

便携版不包含第三方模型。首次使用请将两个部署脚本与 EXE 放在同一目录，先运行 `setup-local-models.ps1`。从旧版升级时不会删除旧目录；首次启动 1.0.0 会从旧应用数据目录复制用户配置。
