# 腾讯会议线上面试助手 0.3.2 — 首次开源

这是“腾讯会议线上面试助手”原创应用代码的首次公开版本。项目面向通用线上面试场景，并对金融与会计相关问题进行专项优化。

项目由金融专业学生发起并主导产品设计，开发过程使用 AI 编程工具辅助实现与测试。由于开发者的专业背景，本项目针对金融、会计、审计、估值和银行风险面试做了专门优化，但不限于这些岗位。

## 主要功能

- 中文优先 SenseVoice 识别与 Silero VAD；
- 金融/会计同音词纠错；
- 针对陈述式面试要求的问题检测；
- 本地金融会计知识检索；
- “结论 / 逻辑 / 注意”式回答抓手；
- 完全本地的 Ollama + Qwen 推理，不需要云端 API Key；
- 固定高度、支持滚轮查看完整回答的置顶小窗。

## Release 附件

- `TencentMeetingCoach-Local-0.3.2-portable.exe`：Windows 便携版；
- `setup-local-models.ps1`：将模型和运行时部署到 `E:\TencentMeetingCoachLocal`；
- `SHA256SUMS.txt`：附件完整性校验值。

便携 EXE 没有商业代码签名，Windows 首次运行可能显示 SmartScreen。它不包含模型，请先执行模型部署脚本。模型和运行时预计占用约 12 GB，实际大小会随 Ollama 与模型版本变化。

发布前已使用当时最新的 Windows Defender 病毒定义进行自定义扫描，未发现威胁；这不构成绝对安全保证，请同时核对 `SHA256SUMS.txt`。

## 发布范围

仓库公开原创源码、知识条目、纠错规则、界面和部署/测试脚本。Release 便携版包含 Electron 运行时及其许可证，但不包含 SenseVoice、Silero VAD、sherpa-onnx、Ollama、Qwen、Python 运行时或模型权重。

## 使用边界

请只在面试方明确允许 AI 辅助、笔记工具或无障碍工具时开启。本项目不包含防检测功能，不保存原始音频，也不能替代当前会计准则、审计规范或专业意见。
