# 腾讯会议线上面试助手 0.3.3

本版本解决连续监听时，面试者回答可能被误判为新问题并覆盖上一条提示的问题。

## 新增

- 底部历史问答导航，可使用左右箭头翻阅本次运行中已生成的问答；
- 回答区域仍支持鼠标滚轮查看长内容；
- 新增文本级答题保护，首个回答生成后仅响应高置信度的新问题。

## 误触发抑制

- 忽略疑似第一人称面试者回答；
- 忽略与上一条回答高度相似的回声内容；
- 忽略连续重复识别到的同一问题；
- 保留对明确问句、明确作答指令和财会陈述式题目的识别能力。

当前音频输入为 Windows 回环音频，不包含腾讯会议提供的说话人身份元数据。本版本没有引入需要录制声纹和校准样本的重型人物识别模型。
